# Tesela

Sandbox de bloques en 3D y supervivencia para móvil (en horizontal) y ordenador: tala, excava, fabrica herramientas, construye y sobrevive a la noche en un mundo infinito.

**Jugar:** https://xevizaera.github.io/tesela/

Se puede instalar como app desde Chrome o Edge (botón «Instalar como app» del menú o el icono de instalar del navegador) y funciona sin conexión después de la primera vez. Las partidas se guardan en el propio dispositivo; para moverlas entre dispositivos usa Partidas → Exportar e Importar.

Hecho con three.js r128. Todo el juego está en `index.html`.
